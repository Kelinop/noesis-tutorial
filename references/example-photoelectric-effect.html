光电效应：频率才是门槛，光强只决定数量

三个实验事实、一套失败预言、一个光量子假设：光电效应如何证明「光的能量是一份一份的」，并亲手拆掉了波动说的统治地位。

01PROB. 原始问题 · THREE FACTS

01三个实验事实：波动说一条也解释不了

1887 年赫兹在做电磁波实验时偶然发现：紫外线照射金属电极会释放电子（光电效应）。勒纳（1902）系统测量后，三个事实浮出水面——它们都违背波动说的直觉：① 光的强度越大，光电子数量越多，但每个光电子的最大动能与光强无关；② 存在红限频率：频率低于 ν₀ 的光，无论多强都不产生光电子；③ 光照与出射之间没有可测量的延迟（<10⁻⁹ s）（见图 1）。

事实

红限频率存在；最大动能随频率线性增长；光强只增加电子数量；无延迟出射。

波动说把能量算在「光强」头上——按波动模型，弱光照射下电子要积累能量好几秒才能逃逸，且任何频率只要够强都能打出电子。

缺口

实验指着同一个方向：能量交付不是「均匀淋雨」，而是「整包交易」——频率决定每包的大小，光强决定包的个数。

波动说的失败不在强度——在「能量必须按频率分级」这个事实。
本质 · ESSENCE

本质钩：频率是门槛，光强是人数

02

把光想成一发一发子弹（光子）：每一发的能量 E = hν 由频率决定——频率太低（λ 太长），单发子弹的能量不够击穿金属的逸出功，子弹再多（光再强）也打不出电子；频率达标后，每发子弹恰好能打出 一个 电子，多余能量变成它的动能。光强只是「每秒多少发子弹」——所以它只改变数量，不改变单发能量。

这个模型的断裂点：子弹模型只解释了「能量整包交付」，没有解释「波」的另一半——干涉、衍射依然需要波动图像。光同时是波和粒子，这个「同时」在量子力学里由波函数统一，经典模型只能二选一。

03QUANTA 机制 · THE MECHANISM

03爱因斯坦的账本：hν = W₀ + Ek

爱因斯坦（1905）把普朗克的能量子假设用到光电效应上：一包能量 hν 进入金属，先付逸出功 W₀（把电子拉出表面的最低门票），剩余的全部变成电子动能。所以最大动能 Ek = hν − W₀——频率线性项，没有光强项（见图 1）；Ek = 0 时得到红限 ν₀ = W₀ / h（见图 2）。

定义 · 爱因斯坦光电效应方程

hν = W₀ + Ek max——Ek max = hν − W₀；红限 ν₀ = W₀/h，λ₀ = hc/W₀。

物理含义：能量以量子 hν 整包交付；W₀ 是金属表面「最低门票」，与频率无关；Ek max 与频率成线性关系，与光强无关——三条实验事实一条方程全收。

WORKED EXAMPLE · λ = 400 nm 打在 W₀ = 2.0 eV 的钠上
步骤操作结果
1光子能量 E = hc/λ = 6.626×10⁻³⁴ × 3×10⁸ / 4×10⁻⁷4.97×10⁻¹⁹ J
2换算电子伏：÷ e = ÷ 1.6×10⁻¹⁹≈ 3.1 eV
3最大动能 Ek = hν − W₀ = 3.1 − 2.01.1 eV
4红限核对：λ₀ = hc/W₀ ≈ 620 nm > 400 nm → 能出电子 ✓自洽

速算：hc ≈ 1240 eV·nm——E(eV) = 1240/λ(nm)，λ = 400 → E = 3.1 eV，一步到位。

04CONFLICT 误解 · WAVE VS QUANTA

04波动说在三个预言上全部落败

经典预言（波动说）：光强 = 能量密度，光越强电子动能越大；任何频率只要足够强都能打出电子；弱光需要时间积累能量（秒级延迟）。

实验事实：动能与光强无关、只随频率线性增长；低于红限永远打不出；出射无延迟（<10⁻⁹ s）。三条预言全部反着来。

波动说：「光就是电磁波，能量连续分布——强光能量大，电子当然更容易被打出来。」
光量子说：能量是整包交付的。强光只是「包的个数多」，每包的大小仍由频率决定——包不够大（低于红限），再多包也打不出电子。频率定门槛，光强定人数。
波动说：「弱光照射，电子在金属里多积累一会儿能量，总会攒够吧？」
光量子说：按波动模型，微弱的紫光要让电子攒够 2 eV 需要数秒；实测出射延迟小于 10⁻⁹ 秒——能量不是攒的，是瞬间整包到的。这一条直接判了波动说的死刑。
波动说：「那把光再加强一点，电子的动能总能大一点吧？」
光量子说：光强（光子数）改变的是光电子数量，不改变最大动能；频率改变的才是最大动能。把光强加倍：饱和光电流加倍，截止电压不变——反直觉但必考。

05截止电压与 I–V 曲线：动能如何被「量」出来

06IMPACT 系统影响 · DUALITY

06光既是波又是粒子：物理学的第一次「二象性」

光电效应证明光有粒子性（能量整包），干涉衍射证明光有波动性——两者都是实测。这个矛盾没有「二选一」的答案：量子力学用波函数同时容纳两者，而光的二象性反过来启发了德布罗意（1924）：既然光有粒子性，粒子是否也有波动性？——物质波假说由此诞生，量子力学的波动力学版本（薛定谔方程）就此展开（见图 6）。

应试技巧：光电效应计算三件套——① E(eV) = 1240/λ(nm)（背住 hc ≈ 1240 eV·nm）；② Ek = E − W₀；③ 红限判断 E ≥ W₀。单位统一（J ↔ eV）是失分重灾区：出 eV 结果先问自己「÷e 了吗」。

Q2 · 光强加倍，截止电压如何变？光强加倍 → 光子数加倍 → 光电流（饱和）加倍，截止电压不变（V₀ 只由频率与 W₀ 决定，即第 04 节对话的最后一问）；题设若同时提高频率，V₀ 按 ΔV₀ = (h/e)·Δν 增大。Q3 · 由 V₀–ν 图求 h 与 W₀：斜率 = h/e → h = 斜率 × e；延长线与 ν 轴交点 = 红限 ν₀ → W₀ = h·ν₀——两条信息一条直线全给（见图 5）。

易错 · 三种「加倍」各改什么

光强加倍 → 电子数量加倍；频率加倍 → 动能按 hΔν 增加；照射面积加倍 → 数量加倍（单位面积不变）。考题混用三者时，先写 hν = W₀ + Ek，再问每个量进了哪一项。
