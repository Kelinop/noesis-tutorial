01PROB. 原始问题 · THE PROBLEM

01减法电路：晶体管成本翻倍的第一个路口

加法器只需要一种电路：逐位相加 + 进位链。但计算机必须能算减法。最直觉的做法是为减法单独造一套减法器——按位借位、符号单独处理。代价是晶体管数量几乎翻倍：1960–70 年代的芯片上，这直接决定一块芯片能不能装进一个机箱。硬件成本是第一道工程压力，但真正难的不是减法器本身，而是负数的表示（见图 1）。

问题

减法与加法是两种不同的算术运算，符号位还要单独判断大小——电路复杂、速度慢。

本质 · ESSENCE

本质钩：把 256 个数字摆在一个钟面上

02

把 256 个数字摆在一个钟面上：0 到 127 是正数，128 到 255 是负数（−128 到 −1）。加法就是顺时针走，走够一圈溢出、剩下的就是结果。从 5 出发顺时针走 251 步，几乎绕满一圈落在 0 附近——5 + (−5) = 0 不是约定，是钟面几何。符号位只是告诉你站在钟的哪一半。

这个模型的断裂点：钟面只在位宽固定时成立（8 位就是 256 个刻度）。位宽一变，模数变，所有编码同步重排——所以补码永远要声明「n 位补码」，脱离位宽谈补码没有意义。

03原码 · 反码 · 补码——三次尝试的演化

钟面是目标，三种表示法是通往它的三次尝试。以 8 位为例，同一批数（+5、−5、+0、−0、−128）在三种表示法下的位模式（见图 2a–2c）：

演化逻辑是一条失败链：原码把符号当标签，减法要判断符号、比较绝对值，加法器帮不上忙；反码让负数是正数的镜像，加法器能算减法，但进位要「循环回绕」（end-around carry）——多一步额外电路，而且 ±0 两个零让判等变得别扭；补码把负数定义为 2ⁿ − X，循环进位消失，零唯一。三者的关系一句话：补码 = 反码 + 1，而那个「+1」恰好把 −0 的位置让给了 −128。

定义 · 补码

n 位补码：−X（0 < X ≤ 2ⁿ⁻¹）的补码定义为 2ⁿ − X；等价地，对 X 按位取反再加 1。范围 [−2ⁿ⁻¹, +2ⁿ⁻¹ − 1]（8 位：−128..+127）。

物理含义：补码是「模 2ⁿ 下的加法逆元」——X 的补码就是钟面上从 0 逆时针走到 −X 的那段距离，所以 X + (−X) ≡ 0 (mod 2ⁿ)。

「取反加一」不是魔法，它在钟面上看得一清二楚：−5 的补码 = 256 − 5 = 251 = 11111011。验证：5 + (−5) = 00000101 + 11111011 = 1 00000000——第 8 位的进位 1 被丢弃（8 位装不下），剩 00000000 = 0（见图 3）。丢弃进位不是误差，它正是取模。

BLUEPRINT CALLOUT · 机制放大

丢弃进位 ≠ 丢弃错误——8 位加法器的第 9 位进位 C₈ 不是结果的一部分，而是「绕钟面一整圈」的标记：结果落在 [0, 256) 内自动取模。反码做不到这一点（要额外回绕进位），所以补码的硬件比反码少一根线。

04RANGE 机制 · RANGE & OVERFLOW

04为什么范围不对称：−128 多出来的一个数

钟面有 256 个刻度，0 占掉一个，剩下 255 个要分给正负两边——正数只有 127 个（1..127），负数却有 128 个（−1..−128）。因为 0 的正负表示合并了：补码里 00000000 只有一种含义，省出来的位置给了 −128。这是补码的「不对称红利」：范围 [−128, +127]，负半边多一个（见图 5）。

易错 · 溢出 ≠ 进位

丢弃 C₈ 是正常取模，不是溢出；溢出只发生在符号位被改写（同号相加得异号）。5 + (−5) 丢弃进位但结果正确；100 + 60 没有丢弃进位（C₈=0）却得出 −96——后者才是溢出。判断题先问「结果符号对吗」，再问「有没有进位」。

05TRADEOFF 权衡 · TRADEOFF

05这笔交易的代价：可读性让位给硬件

补码把硬件成本压到最低，代价写在人的阅读体验上：人类看 11111011 不会立刻读出「−5」，调试时要先做一遍取反加一的心算；而且位宽必须固定——把 8 位补码扩展成 16 位要符号扩展（高位补符号位），写错符号扩展是经典 bug（见图 6）。

06手算三连：转换 · 验证 · 溢出

补码的考点集中在三个动作，每个都必须能当场验算。以下全部用 8 位、真实数值逐步推导：

WORKED EXAMPLE 1 · 转换：−27 的 8 位补码
步骤操作结果
1|−27| = 27 的二进制0001 1011
2按位取反1110 0100
3加 11110 0101
4验证：27 + (−27)0001 1011 + 1110 0101 = 1 0000 0000 → 0 ✓

速算技巧：从最低位找第一个 1，该位左侧全部取反——1110 0101 的末位是 1，左侧 1110 010 取反得 0001 101 = 27 ✓。两种方法可互验。

WORKED EXAMPLE 2 · 判读：0x9C 的十进制值
步骤操作结果
1符号位 b₇ = 1 → 负数负数
20x9C = 1001 1100，取反0110 0011
3加 10110 0100 = 100
4加负号−100

验算：−100 的补码 = 2⁸ − 100 = 156 = 1001 1100 ✓——用 2ⁿ − X 直算与取反加一互验。

WORKED EXAMPLE 3 · 溢出：125 + 10 在 8 位补码下
步骤操作结果
1125 = 0111 1101，10 = 0000 1010相加
2逐位相加（含进位链）1000 0111
3读结果：b₇=1 → 负数，值 = −121同号得异号
4判定：C₇=0、C₈=1，异或 = 1溢出，结果无效

125 + 10 = 135 > 127，必然溢出——钟面走过头了。考试陷阱：让你算 8 位补码 125+10 时，正确回答是「溢出」，不是 −121。
