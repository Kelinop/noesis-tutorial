ELECTROMAGNETISM · 电磁学

麦克斯韦方程组：从不对称到自洽

从库仑到麦克斯韦：四条定律如何被组织成统一的电磁理论，为什么方程组给出光速，以及光速不变如何迫使经典时空观让位。

01PROB. 原始问题 · THE PROBLEM

0119 世纪中叶：电学一套、磁学一套、谁也不知道光和它们有关

1860 年代，电磁学是一堆互不关联的实验定律：库仑的静电力反平方定律、安培的电流力定律、法拉第的电磁感应——它们各自精确，但彼此没有统一的数学框架。更刺眼的是不对称：变化的磁场能产生电场（法拉第，1831），但变化的电场似乎不能产生磁场（当时没人检验过）。物理学从来不喜欢这种「一边有、一边没有」的缺口（见图 1）。

问题

四组定律各自为政：静电场、静磁场、感应、电流磁效应——没有统一的数学语言。

↓
压力

对称性缺口：法拉第证明了「动磁生电」，反向的「动电生磁」却无人检验——理论不允许这种跛脚。

↓
方向

麦克斯韦（1864）：假设「变化的电场也产生磁场」（位移电流），把四定律焊成一个方程组——并算出方程组自己会传播波动。

物理学修补的不是「实验不够」——是「对称性缺了一半」。
本质模型 · ESSENCE MODEL

用「对称性补偿」串起方程演进

02

看麦克斯韦方程组，别数方程——看对称性：两个「散度」方程管场的来源（电荷有源、磁荷无源），两个「旋度」方程管场的变化（法拉第：磁变生电；麦克斯韦补上：电变生磁）。最后一个方程不是新实验，是对称性要求补上的半块拼图——而补上它之后，方程组自己开始「震荡」，震荡的传播速度恰好等于光速。

这个模型的适用边界：对称性只是美学指引，不是物理证明——位移电流之所以成立，靠的是它预言的现象（电磁波）被赫兹 1888 年实验证实。对称性负责提问题，实验负责给答案。

03HISTORY 演进 · HISTORY

03百年时间线：每个方程背后都有一个实验

四个方程不是一次写成的，是三个时代的实验各自贡献一块（档案节：timetable 不进图版、ochre 不与 L2 相邻）：

1785
库仑扭秤实验——电荷间静电力反平方律（高斯定律的实验基础）。
1820
奥斯特：通电导线使磁针偏转——电流产生磁场（安培定律的实验起点）。
1820s
安培：电流元之间的力定律，建立磁学数学框架。
1831
法拉第：电磁感应——变化的磁场产生电场（法拉第定律）。
1864
麦克斯韦《电磁场的动力学理论》：位移电流 + 四方程 + 预言电磁波速度 = 光速。
1888
赫兹实验：产生并探测电磁波，证实麦克斯韦预言。
档案签 · HISTORICAL RECORD

「我们很难避开这样的结论：光是一种电磁波，它以波动形式穿过电磁场，并按照电磁定律传播。」

—— 麦克斯韦《电磁场的动力学理论》（1864/1865 发表），原文意译；该结论标志着光学并入电磁学
04FOUR EQ. 机制 · THE FOUR EQUATIONS

04四个方程：从实验事实到对称性闭合

把四个方程按「递进」排成阶梯——每一级建立在前一级之上，最后一级（位移电流）是纯理论的对称性补丁，却让整个方程组闭合（层级色阶：级位即进度）：

1高斯定律：∮E·dA = Q/ε₀——电场线从正电荷出发、终止于负电荷。实验基础：库仑（1785）。
2高斯磁定律：∮B·dA = 0——磁力线永远闭合，没有磁单极。对称性的一半：磁场无源。
3法拉第定律：∮E·dl = −dΦ_B/dt——变化的磁场产生电场（1831）。不对称出现了：磁变生电。
4安培-麦克斯韦定律：∮B·dl = μ₀(I + ε₀ dΦ_E/dt)——麦克斯韦补上「变化的电场产生磁场」（位移电流）。对称性闭合，方程组自洽。
方程管什么实验基础
∮E·dA = Q/ε₀电荷 → 电场（有源）库仑 1785
∮B·dA = 0磁场无源（磁力线闭合）实验无磁单极
∮E·dl = −dΦ_B/dt磁变 → 电场法拉第 1831
∮B·dl = μ₀(I+ε₀dΦ_E/dt)电流/电变 → 磁场奥斯特 + 麦克斯韦补丁

记忆法：两个散度管「场从哪来」（电荷有源、磁无源），两个旋度管「场怎么变」（互变）。前三个是实验总结，第四个是理论补丁。

档案注：高斯定律的完整形式（含介质与积分域修正）要等到 1867 年前后由后人整理成型——麦克斯韦 1864 年的论文里用的是他自创的「四元数/分量」记号，现代矢量形式是后人重写。

05DISPLACEMENT 机制 · DISPLACEMENT CURRENT

05位移电流：安培定律在电容器处的崩溃

安培环路定律（∮B·dl = μ₀I）有个致命漏洞：穿过回路取一个「张在导线上的面」，有电流 I；把面翻过去穿过电容器极板之间的空气，那里没有电荷流动，I = 0——同一个回路的磁场积分出现两个答案，定律不自洽（见图 2）。麦克斯韦的补丁：极板间虽然无自由电荷流动，但电场在变化，ε₀ dΦ_E/dt 与 I 扮演同一个角色——位移电流。

易错 · 位移电流不是电流

位移电流不涉及电荷移动——它是「变化的电场」的别名（ε₀ dΦ_E/dt 的量纲与电流相同，仅此而已）。考试问「电容器充电时极板间有电流吗」——自由电荷没有，位移电流有（等效）。说「位移电流是电荷流动」即错。

06LIGHT 机制 · LIGHT IS EM

06方程组自己会震荡：c = 1/√(μ₀ε₀)

把四个方程联立，E 和 B 互相「喂养」：变化的电场产生磁场，变化的磁场又产生电场——解出来的波动方程自带传播速度 1/√(μ₀ε₀)。把当时的测量值代入：μ₀ = 4π×10⁻⁷、ε₀ ≈ 8.85×10⁻¹²，算出 ≈ 3×10⁸ m/s——与光速测量值一致。这个「巧合」是 19 世纪物理学最著名的一次脱稿演出：麦克斯韦根本没在找光，是方程自己喊出来的（见图 3）。

定义 · 电磁波

电磁波：E 与 B 互相垂直、垂直于传播方向的横波；真空中所有频率传播速度均为 c。可见光只是电磁波谱中 380–760 nm 的一个窗口。

物理含义：波动解的存在不依赖任何介质——这是「以太」假说最终被淘汰的数学伏笔（相对论再补一刀）。

07IMPACT 系统影响 · SYSTEM IMPACT

07光速不变：一场意外推翻牛顿时空

麦克斯韦方程组给出的光速是绝对的——它由 μ₀、ε₀ 决定，不依赖参考系。这与牛顿力学的速度叠加直接冲突（在匀速运动的火车上光应该变快/变慢）。这个矛盾悬了 40 年，爱因斯坦（1905）选择相信方程组：光速不变，时空必须让步——狭义相对论由此诞生。方程组的一次「脱稿演出」，最终改写了时间与空间本身（见图 5）。

应试要点：麦克斯韦方程组在考题中的三个常驻问法——① 位移电流的作用（修自洽 + 补对称性）；② 为什么预言光速（波动解速度 = 1/√(μ₀ε₀)）；③ 方程组与相对论的关系（光速绝对 → 时空相对）。答 ② 时写出 c = 1/√(μ₀ε₀)、代入常量并比较光速量级；这些是常见评分点，实际得分以题目要求与评分标准为准。

08TRADEOFF 权衡 · TRADEOFF

08统一的代价：方程从「实验总结」变成了「公理体系」

四方程统一了电、磁、光，也改变了理论的组织方式：加入位移电流后，方程组不再只是分立的实验总结，而能作为经典电动力学的基本框架产生可检验的预言。它与洛伦兹力共同连接场和带电粒子，在介质中还需要相应的本构关系；进入高速与微观情境时，则分别显现相对论形式与量子电动力学的适用边界。统一并没有取消边界，而是让边界表达得更清楚。

1864
方程组发表（《电磁场的动力学理论》）
c
波动解速度 = 光速（2.998×10⁸ m/s）

麦克斯韦不是为公式补妆——他让方程满足电荷守恒，并从中读出电磁波与光。
